# Contributing to CodeMind 2026

Thank you for your interest in contributing to CodeMind 2026!

CodeMind 2026 is a programming learning program organized by the Department of Education & Development Insight, FASILKOM UEU Tangerang.

This repository contains learning materials, practical exercises, source code, and documentation from the CodeMind 2026 coding class.

## How to Contribute

Contributions are welcome, especially improvements that help students understand the learning materials.

You can contribute by:

- Fixing documentation errors.
- Improving explanations.
- Correcting source code issues.
- Adding missing practical examples.
- Improving code readability.
- Reporting bugs or documentation issues.

## Contribution Guidelines

Please follow these guidelines:

1. Keep contributions relevant to the original learning materials.
2. Do not change the intended learning objectives.
3. Use clear and descriptive filenames.
4. Keep C++ examples simple and beginner-friendly.
5. Include explanations for significant code changes.
6. Test source code before submitting changes.
7. Do not commit compiled binaries or temporary files.

## Pull Request Process

1. Fork the repository.
2. Create a descriptive branch.
3. Make your changes.
4. Test your changes.
5. Submit a Pull Request with a clear description.
6. Wait for review and feedback.

## Code Style

- Use meaningful variable names.
- Keep indentation consistent.
- Prefer readable code over unnecessary complexity.
- Add comments when they help explain important logic.

## Scope

This repository documents the completed CodeMind 2026 learning activities.

Contributions should preserve the original academic context and historical learning materials.

Thank you for helping improve CodeMind 2026!
