# 🚀 Code Mind Week 3 - Function
Selamat datang di repository Code **Mind Week 3.**

Pada pertemuan ketiga CODE MIND, peserta mempelajari konsep Function dalam bahasa pemrograman C++. Materi ini bertujuan untuk membantu peserta memahami cara membuat program yang lebih terstruktur, efisien, dan mudah dipelihara dengan memanfaatkan function.

---

## 📚 Materi yang Dipelajari
### 🔹 Pengenalan Function
- Apa itu Function
- Manfaat Function
- Cara kerja Function
### 🔹 Function dengan Parameter
- Mengirim data ke dalam Function
- Penggunaan parameter untuk membuat Function lebih fleksibel
### 🔹 Return Value
- Perbedaan cout dan return
- Mengembalikan nilai dari Function
- Menggunakan hasil Function untuk proses lainnya
### 🔹 Jenis Return Type
- void
- int
- float
- double
- char
- string
- bool
### 🔹 Studi Kasus
- Program perkalian menggunakan Function
- Program ganjil dan genap
- Program perhitungan luas
- Program faktorial sederhana

---

## 🎯 Tujuan Pembelajaran

Setelah mengikuti pertemuan ini, peserta diharapkan mampu:
- Memahami konsep dasar Function.
- Membuat Function dengan parameter dan return value.
- Mengurangi pengulangan kode menggunakan Function.
- Membuat program yang lebih terstruktur dan mudah dipahami.
- Mengimplementasikan Function dalam studi kasus sederhana.

---

## 💻 Latihan

Beberapa latihan yang diberikan pada pertemuan ini:
- Membuat Function perkalian dua bilangan.
- Membuat Function untuk menentukan bilangan ganjil atau genap.
- Membuat Function menghitung luas bangun datar.
- Membuat Function faktorial.
- Menggabungkan Function dengan materi sebelumnya seperti:
    1. Variabel
    2. Percabangan
    3. Perulangan
    4. Array

---

## 🛠️ Tools
- C++
- Visual Studio Code
- GCC / MinGW Compiler

## 📌 Catatan

Materi Function merupakan fondasi penting dalam pemrograman karena hampir seluruh proyek perangkat lunak menggunakan Function untuk membagi program menjadi bagian-bagian yang lebih kecil dan terstruktur.

***"Write once, use many times."***
